# Legacy Python Status (1.3.x)

The Python 1.3.x implementation of Escape the Valley is legacy from this release onward.

- **Bug-fix-only maintenance:** The Python 1.3.x line is frozen to bug fixes only.
- **New development in Rust 2.0:** All new content, features, and gameplay mechanics go to the Rust 2.0 game.
- **Continued installability and verification:** The Python package remains installable and is kept to verify existing 1.3.x saves and XRPL trail ledgers.
