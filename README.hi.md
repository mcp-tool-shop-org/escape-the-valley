## यह क्या है?

एस्केप द वैली एक ओरेगन ट्रेल-शैली का सर्वाइवल गेम है जो आपके टर्मिनल में चलता है। यात्रियों के एक समूह को प्रक्रियात्मक रूप से उत्पन्न जंगल में ले जाएं। घटनाओं, खतरों और कठिन विकल्पों का सामना करते हुए भोजन, पानी, गाड़ी की स्थिति और मनोबल का प्रबंधन करें।

एक वैकल्पिक एआई गेम मास्टर (ओलामा द्वारा संचालित) तीन अलग-अलग कहानी कहने वाली आवाजों के साथ आपकी यात्रा का वर्णन करता है। एक वैकल्पिक एक्सआरपीएल टेस्टनेट लेजर बैकपैक आपके आपूर्ति परिवर्तनों को ऑन-चेन रसीदों के रूप में ट्रैक करता है - यह प्रमाण कि आप जीवित रहे, या यह प्रमाण कि आपने कोशिश की।

## क्या नया है

**1.2.0** — GitHub रिलीज़ बाइनरी लॉन्च (इवेंट लाइब्रेरी + स्टाइलशीट बंडल; स्मोक असर्ट `--help` और ≥200 इवेंट)। `trail ledger proof` लोड किए गए सेव की जांच करता है। TUI बीज/सिद्धांत/मोड़/मनोबल दिखाता है; `c` गति को बदलता है; लेजर मेनू `R` इस सेव को प्रमाणित करता है। HUD 80×24 और 120×30 पर पठनीय है।

**1.1.1** — `pip install "escape-the-valley[voice]"` वास्तव में स्थापित होता है (अतिरिक्त ने एक अप्रकाशित पैकेज पिन कर दिया था)। PyInstaller बाइनरी अब वॉयस एक्स्ट्रा को शामिल नहीं करता है।

**1.1.0** — स्ट्रीमिंग कथन, वर्गीकृत अंत, ऐसे इवेंट जो घाव पहुंचा सकते हैं, ऑन-लेजर समाधान प्रमाण, रन कलाकृतियाँ।

v1.1.0 और v1.1.1 GitHub रिलीज़ से जुड़े बाइनरी लॉन्च नहीं होते हैं (फ्रोज़न एंट्रीपॉइंट में एक सापेक्ष आयात)। `pip install escape-the-valley` या v1.2.0+ GitHub बाइनरी / `npx` लॉन्चर का उपयोग करें।

## त्वरित शुरुआत

```bash
pip install escape-the-valley

# Zero-prerequisite npm launcher (v1.2.0+ GitHub binaries; v1.1.0 and v1.1.1
# artifacts do not start):
#   npx @mcptoolshop/escape-the-valley tui --seed 42

# Launch the full-screen TUI (recommended)
trail tui --seed 42

# Resume a saved game
trail tui --continue

# Spoken voice (opt-in; needs pip install "escape-the-valley[voice]").
# AI narration is already on by default when Ollama is running;
# pass --gm-off to disable the GM. --voice does not turn the GM on.
trail tui --seed 42 --voice

# With voice pacing control
trail tui --seed 42 --voice --voice-pace slow

# Without AI narration (deterministic mode)
trail tui --seed 42 --gm-off

# Use a specific Ollama model
trail tui --seed 42 --model mistral
```

## कैसे खेलें

प्रत्येक मोड़ पर आप शिविर से एक क्रिया चुनते हैं:

| क्रिया | यह क्या करता है |
|--------|-------------|
| **Travel** | घाटी के निकास की ओर बढ़ें। भोजन और पानी की लागत आती है। टूटने और घटनाओं का जोखिम। |
| **Rest** | समूह को ठीक करें, मनोबल को पुनर्प्राप्त करें। आपूर्ति की लागत आती है लेकिन कोई प्रगति नहीं होती है। |
| **Hunt** | भोजन के लिए एक मौका पाने के लिए गोला-बारूद खर्च करें। जंगलों और मैदानों में बेहतर। |
| **Repair** | गाड़ी को ठीक करने के लिए एक अतिरिक्त भाग खर्च करें। जीवित रहने के लिए महत्वपूर्ण। |

**घटनाएँ** (A/B/C) विकल्पों के साथ यात्रा में बाधा डालती हैं। सतर्क विकल्प सुरक्षित होते हैं लेकिन समय की लागत आती है। साहसी विकल्प तेज़ होते हैं लेकिन जोखिम भरे होते हैं। कोई हमेशा सही उत्तर नहीं होता है।

**गाड़ी सब कुछ है।** यदि इसमें कोई भाग न होने पर यह टूट जाती है, तो रन समाप्त हो जाता है। इसे आधी स्थिति से ऊपर रखें और अस्थायी ब्रेकडाउन प्रतिरोध के लिए रखरखाव विंडो (आराम करें फिर मरम्मत करें) करें।

**गति** गति बनाम सुरक्षा को नियंत्रित करती है। स्थिर डिफ़ॉल्ट है। कठिन गति अधिक दूरी तय करती है लेकिन अधिक आपूर्ति जलाती है और गाड़ियों को तेजी से तोड़ती है।

**एस्केप वाल्व** (कठिन राशन, हताश मरम्मत, कार्गो छोड़ना) आपात स्थिति के लिए मौजूद हैं। इनके दुष्प्रभाव और कूलडाउन होते हैं - अंतिम उपाय, रणनीतियाँ नहीं।

अधिक गहन सुझावों के लिए, [सर्वाइवल गाइड](https://mcp-tool-shop-org.github.io/escape-the-valley/handbook/survival-guide/) देखें।

## जीएम प्रोफाइल

एआई कथाकार यांत्रिकी को नहीं, बल्कि स्वर को आकार देता है। तीनों प्रोफाइल एक ही गेम खेलते हैं।

- **क्रॉनिकलर** — जमीनी, व्यावहारिक, संक्षिप्त। न्यूनतम लोककथाएँ। रिपोर्ट करता है कि क्या हुआ।
- **फायरसाइड** — गंभीर अलाव कथाकार। सूक्ष्म अलौकिक क्षण। डिफ़ॉल्ट।
- **लैंटर्न-बेयरर** — अलौकिक और सीमांत, लेकिन फिर भी परिणामों में जमीनी। अजीब वाला।

`--gm-profile` के साथ सेट करें: `trail tui --gm-profile lantern`

## आपूर्ति

गेम दो श्रेणियों में 12 प्रकार के संसाधनों को ट्रैक करता है:

**खपत योग्य:** भोजन, पानी, जलाऊ लकड़ी, दवाएं, नमक, गोला-बारूद, लालटेन का तेल, कपड़ा

**उपकरण:** भाग, रस्सी, उपकरण, जूते

5 मुख्य आपूर्ति (भोजन, पानी, दवाएं, गोला-बारूद, भाग) सबसे महत्वपूर्ण हैं। विस्तारित आपूर्ति जैसे जलाऊ लकड़ी, नमक, लालटेन का तेल और कपड़ा गहराई जोड़ते हैं: जलाऊ लकड़ी रात के शिविरों को ईंधन देती है, नमक भोजन की खराबी को रोकता है, लालटेन का तेल सुरक्षित रात की यात्रा को सक्षम बनाता है, और कपड़ा उपकरणों और गाड़ी के कवर को पैच करता है।

## लेजर बैकपैक (वैकल्पिक)

लेजर बैकपैक आपके 5 मुख्य आपूर्ति (भोजन, पानी, दवाएं, गोला-बारूद, भाग) को एक्सआरपीएल टेस्टनेट पर टोकन के रूप में ट्रैक करता है। प्रत्येक शहर का चेकपॉइंट ऑन-चेन पर एक निपटान रसीद रिकॉर्ड करता है। आपके रन के अंत में, आपकी ट्रेल लेजर में लेनदेन आईडी शामिल हैं जिन्हें कोई भी सत्यापित कर सकता है।

पूरी तरह से वैकल्पिक। गेम इसे बंद करके समान रूप से चलता है (डिफ़ॉल्ट)। इसे TUI में L मेनू या CLI के माध्यम से सक्षम करें:

```bash
trail ledger enable
trail ledger status
trail ledger reconcile  # retry failed settlements
trail ledger proof      # PASS / FAIL / INCONCLUSIVE on this save
```

TUI में, **L** लेजर मेनू खोलता है; बैकपैक चालू होने पर, **R** इस सेव को प्रमाणित करता है (समान परिणाम)। यह आराम नहीं करता।

इसके लिए `pip install -e ".[xrpl]"` की आवश्यकता होती है ताकि `xrpl-py` निर्भरता काम करे।

## चेतावनी संकेत

डिफ़ॉल्ट रूप से, गेम नए खिलाड़ियों को जल्दी खतरे का पता लगाने में मदद करने के लिए विस्तृत चेतावनियाँ दिखाता है। अनुभवी खिलाड़ी इसे न्यूनतम मोड पर स्विच कर सकते हैं, जो केवल क्लिफ-एज चेतावनियाँ (अंतिम क्षण, गंभीर खतरे) दिखाता है:

```bash
trail tui --callouts minimal
trail new --callouts minimal
```

## समस्या निवारण

**यदि कुछ भी गलत दिखता है, तो पहले `trail self-check` चलाएँ।** यह रिपोर्ट करता है कि क्या ओलामा पहुंच योग्य है, क्या आपका सेव लोड होता है, और कौन सा मॉडल स्थापित है। तीन चीजें जो गलत हो सकती हैं:

| लक्षण | कारण | समाधान |
|---------|-------|-----|
| **Generic / no narration** | ओलामा चल नहीं रहा है (जीएम वैकल्पिक है और यह वापस लौटता है, इससे कोई नुकसान नहीं होता) | ओलामा शुरू करें (`ollama serve`), या `--gm-off` के साथ नियत रूप से खेलें। इसकी पुष्टि करने के लिए `trail self-check` चलाएं। |
| **लेजर लंबित / निपटान विफल** | एक्सआरपीएल टेस्टनेट एक सार्वजनिक परीक्षण नेटवर्क है और कभी-कभी अस्थिर होता है | `trail ledger reconcile` विफल निपटानों को पुनः प्रयास करता है; जब नेटवर्क ठीक हो जाए तो इसे फिर से चलाएं। किसी भी स्थिति में स्थानीय रूप से आपूर्ति सही है। |
| **Save won't resume** | `run.json` लेखन के दौरान छोटा या दूषित हो गया | इंजन इसे अस्वीकार करने से पहले `run.json.corrupt-<timestamp>` के रूप में अलग कर देता है, इसलिए आपकी अगली सहेजी गई फ़ाइल सबूत को नष्ट नहीं कर सकती। उस बैकअप से पुनर्प्राप्त करें, या एक नए बीज से फिर से शुरू करें। |

पहला वर्णित मोड़ मॉडल लोड करता है और इसमें 10-30 सेकंड लग सकते हैं - यह सामान्य है, कोई रुकावट नहीं। पूरी जानकारी: [समस्या निवारण पुस्तिका](https://mcp-tool-shop-org.github.io/escape-the-valley/handbook/troubleshooting/)।

## सुरक्षा

कोई टेलीमेट्री नहीं। कोई खाता नहीं। जीएम कथन डिफ़ॉल्ट रूप से चालू है (स्थानीय ओलामा पर एचटीटीपी); इसे अक्षम करने के लिए `--gm-off` पास करें। एक्सआरपीएल तब तक बंद रहता है जब तक कि `trail ledger enable` न हो जाए (केवल टेस्टनेट)। आवाज वैकल्पिक है (`--voice`)। पूर्ण खतरे मॉडल के लिए [सुरक्षा.एमडी](SECURITY.md) देखें।
